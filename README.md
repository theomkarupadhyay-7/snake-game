# 🐍 Snake Game

A classic Snake Game built with **React, Vite, and Firebase**.

##  Features

-  Classic Snake gameplay
-  Email/Password, Google & GitHub authentication
-  Firebase-powered high scores
-  Mobile virtual controls
-  Start & Restart functionality
-  Persistent login
-  Logout
-  Deployed on Vercel

##  Tech Stack

- React + Vite
- Firebase Authentication
- Cloud Firestore
- GitHub
- Vercel

##  How to Play

Login → Click **Start Game** → Eat the food → Avoid the walls and yourself → Beat your high score! 🏆
